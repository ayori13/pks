### Использованные виджеты
- **Scaffold** — основной каркас экрана с `AppBar` и `body`.  
- **AppBar** — верхняя панель с заголовком.  
- **Column** — вертикальная компоновка элементов.  
- **Text** — вывод текста с изменяемыми стилями (`fontSize`, `fontWeight`, `color`).  
- **ElevatedButton** — кнопка с обработкой события `onPressed`.  
- **Container** — прямоугольная область с заданными размерами и цветом.  
- **Row** — горизонтальное расположение элементов (иконки).  
- **Icon** — встроенные иконки Flutter (`Icons.star`, `Icons.favorite`).  
- **SizedBox** — для отступов между элементами.  
- **ScaffoldMessenger + SnackBar** — показ всплывающего сообщения при нажатии кнопки.  

### Работа со стилями и цветами
- Использовали встроенные цвета (`Colors.blue`, `Colors.green`, `Colors.orange`, `Colors.red`).  
- Задали собственный цвет через `Color(0xFF8E44AD)`.  
- Изменили стили текста с помощью `TextStyle`: размер шрифта (`fontSize`), жирность (`fontWeight.bold`), цвет (`color`).  
- Применили разные цвета к `AppBar`, кнопке и контейнеру.  

### Трудности
- При запуске на **Chrome (web)** возникала ошибка отладки (`Unsupported operation: Cannot send Null`), но приложение работало — проблема была в сервисе отладки, а не в коде.  
- При запуске в Android Studio отображалось предупреждение про отсутствие **Visual Studio toolchain**. Это относится только к Windows Desktop-сборке, для Android и Web оно не критично.  
- Основные сложности решены через настройку среды: использование Android-эмулятора и `flutter doctor` для проверки конфигурации.
