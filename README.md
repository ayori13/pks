## Обработка ошибок и отладка

Для повышения стабильности приложения я реализовал глобальную систему обработки ошибок:

```dart
void main() {
  FlutterError.onError = (details) {
    FlutterError.presentError(details);
    print('Flutter Error: ${details.exception}');
    print('Stack trace: ${details.stack}');
  };

  runZonedGuarded(
    () {
      runApp(const SimpleNotesApp());
    },
    (error, stackTrace) {
      print('Uncaught Error: $error');
      print('Stack trace: $stackTrace');
    },
  );
}
```

Данная реализация позволяет:
- Корректно обрабатывать ошибки Flutter-виджетов
- Перехватывать непредвиденные исключения
- Логировать ошибки для последующего анализа
- Предотвращать аварийное завершение приложения
