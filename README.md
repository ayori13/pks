## Основная функциональность

### Получение геопозиции и определение адреса
Я реализовал метод `_getLocation()`, который выполняет следующие действия:

1. **Проверка доступности сервисов геолокации** — убеждаюсь, что на устройстве включены службы определения местоположения
2. **Запрос разрешений** — запрашиваю у пользователя разрешение на доступ к геолокации
3. **Получение текущих координат** — использую высокую точность для определения местоположения
4. **Обратное геокодирование** — преобразую географические координаты в читаемый адрес

```dart
Future<void> _getLocation() async {
  bool serviceEnabled = await Geolocator.isLocationServiceEnabled();
  if (!serviceEnabled) return;

  LocationPermission permission = await Geolocator.requestPermission();
  if (permission == LocationPermission.denied) return;

  final pos = await Geolocator.getCurrentPosition(
    desiredAccuracy: LocationAccuracy.high,
  );

  List<Placemark> placemarks =
      await placemarkFromCoordinates(pos.latitude, pos.longitude);

  if (!mounted) return;

  setState(() {
    _position = pos;
    _address =
        '${placemarks.first.locality ?? ''}, ${placemarks.first.street ?? ''}';
  });
}
```
