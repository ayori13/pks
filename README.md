# Настройка Supabase

Я создал проект в Supabase и получил ключи для подключения: Project URL и anon key.

Для работы с базой данных в Flutter-приложении я подключил необходимый пакет и выполнил инициализацию клиента Supabase до старта приложения.

Все конфиденциальные данные, такие как приватные ключи, хранятся в безопасности и не включены в публичный код.

Перед продолжением работы я убедился, что приложение успешно запускается без ошибок.

# Установка зависимостей и настройка клиента

В проекте я использовал пакет `supabase_flutter` 2 версии.

Подключение и инициализация выполнены в файле `main.dart`. Клиент настраивается с помощью полученных Project URL и anon key.

В приложении реализована навигация между основными экранами: экраном проверки авторизации (AuthGate) и экраном для работы с заметками (NotesPage).

# Структура базы данных

Для хранения данных я создал таблицу `notes` со следующими полями:
- `id` — уникальный идентификатор записи,
- `user_id` — идентификатор пользователя, владельца заметки,
- `title` — заголовок заметки,
- `content` — содержимое заметки,
- `created_at` — дата и время создания,
- `updated_at` — дата и время последнего обновления.

База данных работает на PostgreSQL с активированной функцией Row Level Security (RLS) для контроля доступа на уровне строк.

# Настройка политик безопасности (RLS)

Для обеспечения безопасности данных я настроил следующие политики доступа:

- **Чтение:** Пользователь может получать только те записи, которые создал сам.
- **Добавление:** Новая заметка может быть создана только от имени текущего авторизованного пользователя.
- **Обновление и удаление:** Изменять или удалять пользователь может исключительно свои собственные заметки.

Все политики применяются только к аутентифицированным пользователям.
