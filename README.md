**Этапы подключения Firebase к проекту:**  
Настройка осуществлялась через Firebase CLI с выполнением команды `flutterfire configure`.  

**Последовательность действий:**  
После авторизации я выбрал проект Заметки в Firebase(также была возможность создать новый).  
Далее настроил поддерживаемые платформы, после чего конфигурационные файлы были сгенерированы автоматически.  

В коде я использовал пакеты `firebase_core` и `cloud_firestore`. Инициализацию Firebase выполнил в файле `main.dart` перед запуском приложения.  

**Примечание по безопасности:**  
На этапе разработки я применял упрощённые правила доступа к Firestore вида `allow read, write: if true`, что открывало полный доступ к данным.  
Для рабочего окружения необходимо заменить эти правила на строгие, с обязательным использованием аутентификации и проверкой прав пользователей.
